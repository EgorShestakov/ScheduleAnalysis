# Расписание и диагностика аудиторного фонда

## Смысл проекта

Проект предназначен для автоматизированного составления учебного расписания в вузе с возможностью **диагностики ресурсных ограничений**. Основная задача — не просто построить расписание, но и, если это невозможно, выявить причины («узкие места»): нехватку вместимости аудиторий или недостаток оборудования.

Решение основано на **трёхуровневом графо-потоковом методе**:

1. **Быстрая проверка** на двудольном графе (критерии существования, алгоритм Куна).
2. **Тактическая коррекция** (снятие ограничений, классификация конфликтов EQ/CAP/ALL, задача о назначениях).
3. **Стратегический анализ** (потоковая модель, 4 модификации сети, алгоритм Диница).

Система позволяет диспетчеру:
- проверить, можно ли разместить все события;
- получить конкретное расписание (или найти оптимальное по штрафам);
- при невозможности — получить количественные рекомендации (увеличить вместимость, добавить оборудование, временные интервалы, удалить события).

## Архитектура

## Назначение файлов

| Файл | Назначение |
|------|-------------|
| `main.py` | Оркестрация всех этапов (согласно схеме алгоритма). |
| `data_models.py` | Классы для сущностей: `Group`, `Room`, `Teacher`, `Event`, `TimeSlot`, `WorkDay`. |
| `data_loader.py` | Чтение CSV → списки объектов Python. |
| `db_loader.py` | Парсинг CSV в SQLite (промежуточное хранилище). |
| `db_writer.py` | Чтение расписания из SQLite и запись в CSV. |
| `graph_builder.py` | Построение двудольного графа `(E, C×T, R1)` и вспомогательной функции `get_all_slots`. |

| `matching.py` | Алгоритм Куна для максимального паросочетания. |
| `diagnostics.py` | Тактическая диагностика: графы без ограничений `H2`, `H3`, `H4`, множества `EQ`, `CAP`, `ALL`, текстовые рекомендации. |
| `flow_filter.py` | Стратегический анализ: построение 4 модификаций транспортной сети, алгоритм Диница, фильтрация слотов по потоку. |
| `assignment.py` | Построение матрицы штрафов, решение задачи о назначениях (венгерский алгоритм). |
| `output.py` | Формирование расписания и вывод в консоль/CSV. |
| `utils.py` | Вспомогательные утилиты (округление, разности оборудования, даты и т.д.). |
| `data_generator.py` | Генерация тестовых CSV (синтетические данные). |

| Файл | Обязательные поля | Описание |
|------|-------------------|-----------|
| `rooms.csv` | `id, capacity, equipment, number` | Аудитории: вместимость, оборудование, номер. |
| `teachers.csv` | `id, surname, name, patronymic, specialisation` | Преподаватели: ФИО, специализация (предметы). |

## Выходные данные

- `schedule_result.csv` — итоговое расписание: дата, номер пары, факультет, группа, событие, аудитория, преподаватель, возможный конфликт (при мнимых расписаниях).

## Алгоритм (краткая схема)

1. Загрузка данных (CSV → объекты / SQLite).
2. Проверка `|E| ≤ |C|·|T|` → при нарушении рекомендации по увеличению ресурсов.
3. Построение двудольного графа, проверка изолированных событий (таблица причин).
4. Поиск совершенного паросочетания (Кун).
   - Если есть и нет временных конфликтов → расписание готово (запрос доп. анализа).
   - Если есть мнимые конфликты → **тактическая коррекция** (снятие ограничений, задача о назначениях).
   - Если паросочетания нет → предложить исключить события, затем тактическая коррекция.
5. При неудаче тактической коррекции или по запросу → **стратегический анализ** (4 модификации сети, Диниц, сравнение потоков, рекомендации по модернизации).
6. Вывод расписания / рекомендаций.
